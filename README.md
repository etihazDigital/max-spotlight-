# MAX SpotLight Atelier — Premium Website

A responsive multi-page front-end concept for Max SpotLight Atelier, Pune.

## Pages
- `index.html` — premium home / brand story
- `programs.html` — program catalogue
- `workshops.html` — workshop/event discovery
- `studio.html` — studio experience + media gallery
- `enrollment.html` — three-step online enrollment demo
- `contact.html` — contact / location

## Assets
There is intentionally ONE media folder: `assets/`.
See `assets/IMAGE-GUIDE.txt` for the exact filename map and placement plan.

## Important
The enrollment UI is functional on the front end and stores a demo submission in localStorage. It does NOT process real payments or send data to a real backend. Before production, connect:
1. a database/CRM,
2. transactional email/WhatsApp confirmation,
3. availability management,
4. a verified payment gateway,
5. privacy/terms/consent pages.
